key points : 

1) we can create n no of classes in single package (not same name for class)
2) we can create n no of objects of a class
3) we can create n no of packages in project(not same name)
4) we can create n no of methods inside the class (static as well as non-static)
classes contains variables and methods whereas objects are created from the class
5) we cant make same methods name in class (we need to used different parameters suppose if you want to used same method name)
6) we cant make local variable static 
7) we cant give any access specifier to the local variables
8) we make global/instance variable as static 
9) we can give any access specifier(public/private/default/protected) to the global/instance variable
10) we can call static things by using the class name like as static methods or static variable ....
11) we can declared local variable inside the methods or block
13) we can declared global variable inside the class or outside the method
